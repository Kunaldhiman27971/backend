Socket.io:->Socket.io ek library hai jo client (browser/app) aur server ke beech real-time communication karwati hai. Isse bina page refresh kiye data instantly send aur receive ho sakta hai.
Isme users server se connection bnake rkhte hai or usi ke through baat cheet hoti hai.

Example: Jab WhatsApp par koi message bhejta hai, to Socket.io ki wajah se dusre user ko message turant dikh jata hai, bina refresh kiye.
